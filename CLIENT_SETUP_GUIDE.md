# AAPSD-Assistant: Client PC Setup Guide

This guide provides the exact step-by-step instructions to configure **Kubernetes**, **Prometheus**, **Redis**, and **Supabase Database** on your Client PC and start the system.

---

## Step 1: Ensure Docker Desktop & Kubernetes Are Running

1. Open **Docker Desktop** on your Client PC.
2. Go to **Settings (Gear Icon)** → **Kubernetes** → make sure **"Enable Kubernetes"** is checked.
3. Wait until the Kubernetes icon in the bottom-left corner of Docker Desktop shows **green / running**.

## Step 3: Start Redis in Docker

In PowerShell, run this command to start the Redis cache container (it automatically cleans up any old container first to prevent conflict errors):

```powershell
docker rm -f aapsd-redis 2>$null; docker run -d --name aapsd-redis -p 6379:6379 --restart always redis:alpine
```

_(If you only want to start an already-existing container without recreating it: `docker start aapsd-redis`)_

---

## Step 4: Start Prometheus Integration in Docker

In PowerShell, run this command to start the Prometheus metrics container on port `9090` (it automatically cleans up any old container first):

```powershell
docker rm -f aapsd-prometheus 2>$null; docker run -d --name aapsd-prometheus -p 9090:9090 --restart always prom/prometheus:latest
```

_(If you only want to start an already-existing container without recreating it: `docker start aapsd-prometheus`)_

## Step 6: Verify Database Migrations (Only Needcomplete new system installation only)

Run this command in PowerShell to ensure the Supabase database tables are created:

```powershell
npm run db:migrate -w apps/api
```

You should see:

```
Migrations complete.
```

## Step 7: Start the Entire System

### 1. Start the Backend API

In your primary PowerShell window, run:

```powershell
npm run dev -w apps/api
```

You should see all environment checks pass with green checkmarks:

```
--- System Environment Checks ---
✅ Database: Connected successfully
✅ Firebase Admin: Initialized successfully
✅ GitHub OAuth: Configured successfully
✅ Kubernetes Adapter: Connected successfully
✅ Prometheus Adapter: Connected successfully
--- Environment Checks Complete ---
```

### 2. Start the Frontend Web App

Open a **new PowerShell window** in the project folder and run:

```powershell
npm run dev -w apps/web
```

Now open **http://localhost:5173** in your browser to access the application!

## Step 8: Troubleshooting & Common Fixes (Client PC)

### 1. Fixing `Firebase Auth Warning: ID token has expired` & `401 Unauthorized`

Why does this happen?

- **Reason A (Windows Clock Out of Sync):** Google Firebase uses strict UTC time. If your Windows 10 clock is ahead or behind Internet time by even 2 minutes, Google rejects new login tokens as "expired" or "issued in the future".
- **Reason B (Cached Token):** The browser has an old token saved from an earlier session.

**How to fix:**

1. Open PowerShell **as Administrator** and sync your Windows clock with Internet time:
   ```powershell
   net start w32time
   w32tm /resync /force
   ```
2. In your Chrome / Edge browser at `http://localhost:5173`:
   - **Method A (Quickest - 100% Guaranteed):** Open a new **Incognito / InPrivate window** (`Ctrl + Shift + N`) and go to `http://localhost:5173`. An incognito window has zero old tokens!
   - **Method B (Clear All Storage including IndexedDB):**
     - Press **F12** to open Developer Tools.
     - Go to the **Application** tab → click **Storage** (the top item in the left sidebar).
     - Click the **"Clear site data"** button (this wipes IndexedDB where Firebase saves logged-in sessions!).
     - Refresh the page (`Ctrl + F5`) and click **Sign in with Google** again.

---

### 2. Fixing `net::ERR_CONNECTION_REFUSED`

Why does this happen?

- Your Backend API server (`npm run dev -w apps/api`) was stopped or closed.

**How to fix:**

- Always keep **two PowerShell windows** open simultaneously:
  - **Window 1:** `npm run dev -w apps/api` (runs backend on port 3000)
  - **Window 2:** `npm run dev -w apps/web` (runs frontend on port 5173)
